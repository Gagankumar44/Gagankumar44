An original generative wire sculpture and learning loop supply the visual identity. The wire surface uses a mathematical projection seeded by `Gagankumar44`; it is decorative artwork, not model or activity data. Both visuals have separate mobile and light-theme versions. The README selects the appropriate artwork using picture sources. CSS animations respect `prefers-reduced-motion`. Project links are kept in one compact table.

Design references: [IBM’s 2x Grid](https://www.ibm.com/design/language/2x-grid/) for disciplined spacing, [Google Design’s Code is a Design Material](https://design.google/library/code-is-a-design-material) for code as a creative medium, and [Processing’s Noise Wave example](https://processing.org/examples/noisewave) for mathematical art. The sculpture’s formula and SVG implementation are original; no external artwork or code was copied.

The current SVGs are generated by `tools/build-ai-lab.mjs` into `ai-lab/`. No JavaScript runs inside the README or SVG images. The earlier control-room assets remain in the repository but are no longer displayed in the README.

## Updating the profile

1. Edit the story, knowledge summary and links in `README.md`.
2. Edit labels, colours and artwork in `tools/build-ai-lab.mjs`.
3. Run `node tools/build-ai-lab.mjs`.
4. Preview on a narrow screen and with reduced motion before committing.
