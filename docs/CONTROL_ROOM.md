# Control-room profile

This profile connects Gagan Kumar’s interests in design, animation, AI experiments, photography, and cinematography with the work currently visible in his public repositories.

## Visual system

- Midnight background: `#080f18`
- Panel surface: `#101c2a`
- Main text: `#eef6fc`
- Secondary text: `#9bb1c3`
- Cyan signal: `#52e0ef`
- Green accent: `#b7f76b`
- Purple for early concepts: `#b5a4ff`

The conceptual idea network, motion-study timeline, chart trace, and idea-workflow panel provide movement without fabricated activity metrics. The hero has a compact version selected by the README’s picture element. CSS animations respect `prefers-reduced-motion`.

All final artwork is code-native SVG generated by `tools/build-control-room.mjs`. These final assets do not use the earlier image-generated concept previews. No JavaScript runs inside the README or SVG images. The panels link to repository content; they are not interactive application windows.

## Updating the profile

1. Edit the human-readable story and links in `README.md`.
2. Edit the SVG source in `tools/build-control-room.mjs` when changing labels, colours or artwork.
3. Run `node tools/build-control-room.mjs`.
4. Preview on a narrow screen and with reduced motion before committing.

The optional PNG avatar is a raster export of `control-room/avatar.svg`. Regenerate it with a vector-to-PNG renderer after editing the SVG. GitHub account settings are separate from this repository.
